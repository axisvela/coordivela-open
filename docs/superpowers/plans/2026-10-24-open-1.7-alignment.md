# COORDIVELA-open 1.7 Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align `COORDIVELA-open` with Core `1.7.0`, complete the public OpenAPI
surface, fix SDK drift, and produce signed `v1.7.0` release artifacts.

**Architecture:** The OpenAPI contract is the source of truth for the public
HTTP surface. The Go SDK mirrors that contract. Core supplies the authoritative
route list and JSON shapes. Release artifacts are built from Core `v1.7.0` and
signed with the repository GPG key.

**Tech Stack:** Go 1.26.9, OpenAPI 3.1, PowerShell, GPG, CycloneDX.

func (c *Client) SymbivelaWorkItemProjection(ctx context.Context, id string) (*SymbivelaWorkProjection, error) {
	var out SymbivelaWorkProjection
	if err := c.do(ctx, http.MethodGet, "/v1/projections/work-items/"+pathEscape(id)+"/symbivela", nil, &out); err != nil {
		return nil, err
	}
	return &out, nil
}

func (c *Client) AttachOpenCodeSession(ctx context.Context, id string, req AttachOpenCodeRequest) (*WorkItem, error) {
	var out workItemResponse
	if err := c.do(ctx, http.MethodPost, "/v1/work-items/"+pathEscape(id)+"/attach-opencode", req, &out, req.IdempotencyKey); err != nil {
		return nil, err
	}
	return out.WorkItem, nil
}
